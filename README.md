Projeto React de loja premium multi-page focado em moda masculina e acessórios.

## Rodar localmente

```bash
npm install
npm start
```

## Porta diferente
Crie um arquivo `.env` na raiz com:

```txt

```

## Build

```bash
npm run build
```
